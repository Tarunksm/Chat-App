````md
# Chat App

Real-time chat application frontend built with Next.js.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Better Auth
- Prisma
- PostgreSQL
- WebSockets

## Features

- Email/password authentication
- Google & GitHub login
- Real-time messaging
- Message history
- Join/leave notifications
- Logout

## Run Locally

```bash
npm install
npm run dev
```
````

Open:

```text
http://localhost:3000
```

## Environment Variables

Create a `.env` file:

```env
DATABASE_URL="your_database_url"
GOOGLE_CLIENT_ID="your_google_client_id"
GOOGLE_CLIENT_SECRET="your_google_client_secret"
GITHUB_CLIENT_ID="your_github_client_id"
GITHUB_CLIENT_SECRET="your_github_client_secret"
```
